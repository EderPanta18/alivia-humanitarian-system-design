# 04-secuencias-automaticas

## Propósito
Ejecuciones internas sin actor humano: matching, integración de observaciones y cierre.

## Contenido
- `AUT-01-matching.puml`: AUT-01 | Matching y recálculo automático.
- `AUT-02-ingesta-externa.puml`: AUT-02 | Ingesta de observaciones externas.
- `AUT-03-informe-final.puml`: AUT-03 | Evento de cierre e informe final.

## Convenciones
Cada archivo `.puml` tiene un propósito específico y contiene código PlantUML editable. Las alternativas y fallos se representan cuando alteran el resultado operativo. No se asume ejecución ni despliegue real.
