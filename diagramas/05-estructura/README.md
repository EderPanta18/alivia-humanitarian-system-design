# 05-estructura

## Propósito
Vistas de dominio, paquetes, componentes y despliegue cloud propuesto.

## Contenido
- `EST-01-clases-dominio.puml`: EST-01 | Clases del dominio.
- `EST-02-paquetes.puml`: EST-02 | Dependencias entre paquetes.
- `EST-03-componentes.puml`: EST-03 | Componentes.
- `EST-04-despliegue.puml`: EST-04 | Despliegue.

## Convenciones
Cada archivo `.puml` tiene un propósito específico y contiene código PlantUML editable. Las alternativas y fallos se representan cuando alteran el resultado operativo. No se asume ejecución ni despliegue real.
